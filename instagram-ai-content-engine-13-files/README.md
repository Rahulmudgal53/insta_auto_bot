A shared Markdown workspace for building a zero-budget-first, AI-assisted Instagram niche page.

## Start here
1. Read `project-context.md`.
2. Read `AGENT_INSTRUCTIONS.md`.

- Faceless screen recordings and original visuals

- Audience growth first; monetization considered from day one
- Automate repetitive work, not originality
- Human approval before publishing
