# Publishing Guide

## Publishing principles
- Publish only content that has passed human review.
- Use official, supported Instagram features or authorized integrations.
- Never assume the account is connected or that an API action succeeded.
- Keep a record of the actual publish date, URL, and content version.

## Pre-publish fields
- Working title
- Final hook
- Final caption
- CTA
- Cover frame
- Accessibility/readability check
- Approval status
- Planned date
- Published URL and timestamp

## Safety
Do not use fake engagement, spam, mass unsolicited DMs, or unofficial methods that risk account security or platform restrictions.
