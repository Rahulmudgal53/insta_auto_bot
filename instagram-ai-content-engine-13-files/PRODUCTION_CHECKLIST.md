# Production Checklist

## Before recording
- [ ] Define the viewer's problem.
- [ ] Prepare a real, repeatable task and input.
- [ ] Define what success means.
- [ ] Verify tool behavior and any factual claims.
- [ ] Remove credentials, private data, and confidential information.

## During recording
- [ ] Show the actual workflow.
- [ ] Capture the key steps clearly.
- [ ] Capture a before/after or other valid result when possible.
- [ ] Do not manufacture outcomes or time savings.

## Editing
- [ ] Clear hook in the first 1–2 seconds.
- [ ] Remove dead time.
- [ ] Keep on-screen text readable on a phone.
- [ ] Make the Reel understandable without sound.
- [ ] Use original visuals and appropriate attribution.

## Final review
- [ ] Claims are supported by the demonstration.
- [ ] Tool names and UI details are correct.
- [ ] Captions and CTA are relevant.
- [ ] No private information is visible.
- [ ] Human approval recorded before publishing.
