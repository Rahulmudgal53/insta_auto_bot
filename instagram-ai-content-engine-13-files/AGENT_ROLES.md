# Agent Roles

Agents can be separate conversations or tools. These are responsibilities, not claims that integrations are already connected.

## 1. Research Agent
Finds audience problems, researches tools, records sources, and flags uncertain claims.

## 2. Idea Strategist
Turns research into original demonstration ideas, scores them, and avoids duplicates.

## 3. Script Producer
Creates hooks, scripts, shot lists, and concise on-screen text.

## 4. QA / Fact Checker
Checks claims, reproducibility, privacy, originality, and whether the demo proves the promise.

## 5. Analytics Analyst
Summarizes real performance data and recommends measurable experiments.

## 6. Monetization Analyst
Tracks possible offers and audience demand without forcing premature sales.

## Handoff rule
Each agent should state what it read, what it produced, what remains uncertain, and the next action. Human approval remains the publishing gate.
