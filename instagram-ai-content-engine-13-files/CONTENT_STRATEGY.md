# Content Strategy

## Positioning
Practical AI workflows that help developers and professionals save time, reduce repetitive work, and use tools effectively.

## Proposed pillars
1. **AI workflow demonstrations** — complete workflows solving real tasks.
2. **AI tools in action** — focused, honest tool demonstrations.
3. **Automation systems** — repeatable workflows using AI, APIs, no-code, or lightweight code.
4. **Developer productivity** — debugging, documentation, testing, and coding workflows.
5. **Work and research productivity** — research, summarization, reporting, and information processing.

## Starting content mix
- 35% workflow demonstrations
- 25% tool demonstrations
- 20% automation systems
- 10% developer productivity
- 10% experiments

Treat the mix as a starting hypothesis; update it using real performance data.

## Quality bar
Prioritize usefulness, demonstrability, novelty, reproducibility, and production effort.
