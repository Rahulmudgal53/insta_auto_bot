# Instagram AI Content Engine

A shared workspace for building a faceless Instagram account around practical AI tools, workflows, automation, and productivity.

## Core Principle
Real demonstrations and useful outcomes are the differentiator. Automate repetitive coordination, not originality.

## Structure
- `project-context.md` — project context
- `agent-instructions.md` — collaboration rules
- `strategy/` — content pillars, 30-day plan, monetization roadmap
- `skills/` — audit of the 13 original skills
- `content/` — ideas, scripts, and publishing log
- `analytics/` — performance tracking
- `experiments/` — hypotheses and results

## First Milestone
Publish and evaluate 10–12 quality Reels before expanding automation or investing in complex infrastructure.
